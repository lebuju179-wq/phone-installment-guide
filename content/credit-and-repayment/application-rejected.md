## 常见原因

| 原因 | 说明 |
|---|---|
| 信用记录空白 | 从没用过信用卡或贷款，机构缺乏判断依据 |
| 近期查询过多 | 短时间内在多个平台申请过 |
| 已有负债较高 | 现有的月供占收入比例高 |
| 有逾期记录 | 特别是近期、多次或金额较大的逾期 |
| 信息不一致 | 填写的工作、收入、联系方式与其他资料对不上 |
| 年龄或身份限制 | 不满足产品的准入条件（如学生、年龄过小或过大） |

具体原因机构通常不会全部告诉你，可以查询自己的信用报告，对照排查。

## 正确的应对

1. **停止连续申请**：被拒后马上去别的平台申请，会增加查询记录，越申请越难通过；
2. **查一下信用报告**：通过中国人民银行征信中心官网等官方渠道查询，确认是否有你不知道的逾期或账户，发现错误可以提出异议；
3. **先改善基础**：按时还清现有债务，间隔一段时间再申请；
4. **调整方案**：降低分期金额，换更便宜的机型，或者用旧机抵扣（见[以旧换新加分期怎么搭配](../platform-compare/trade-in-plus-installment.md)）。

## 警惕"包装""代办"

被拒后常有人主动联系你，声称"内部渠道""包装资料""保证下款"，并先收"服务费""保证金"。这类服务要么是诈骗，要么让你提供虚假资料，风险都在你身上。**不要理会。**
